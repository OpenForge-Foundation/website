Community

OpenForge is built by its contributors. Here's how to get involved.

Your first contribution

  1. Find a project. Browse the projects and pick one that interests you.
  2. Pick an issue. Look through open issues, or open one describing the bug or feature you have in mind.
  3. Fork and build. Fork the repository, clone it with submodules, and follow its README to build locally.
  4. Open a pull request. Keep it focused, add tests where it makes sense, and we'll review it together.

Ways to help

  • Code: C++ cores, Python bindings, tests and tooling.
  • Documentation: tutorials, examples and API docs. See the docs.
  • Feedback: report bugs and tell us about your use cases.

Where we talk

Everything happens in the open on GitHub at OpenForge-Foundation, in issues and pull requests on each project.
