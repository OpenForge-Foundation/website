About

A foundation for fast, open, community-built software for science and engineering.

Mission

OpenForge Foundation exists to empower open-source programming and technology-related content. We build and maintain libraries that make serious computation accessible: native performance where it matters, approachable APIs everywhere else, and source code anyone can read and improve.

Values

  • Performance with clarity. Fast code should still be readable code.
  • Openness. Code, discussion and decisions happen in public.
  • Consistency. Shared conventions across projects so knowledge transfers.
  • Welcoming contributors. Good first issues, honest reviews, and credit where it's due.

How we work

Each project lives in its own repository under the OpenForge-Foundation GitHub organization and follows the same approach: a C++ core, Python bindings, automated tests, and documentation alongside the code.

Governance

OpenForge is in its early days. As the community grows we'll publish a governance model, code of conduct and contribution guidelines here.
