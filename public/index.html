Why OpenForge

Built for speed. Designed for people.

Every OpenForge library follows the same principles, so once you know one, you know them all.

Fast by default

Performance-critical code is written in modern C++ so heavy numerical work runs at native speed.

Pythonic interfaces

First-class Python bindings mean you get C++ speed with the ergonomics of the Python ecosystem.

Open source

Permissively licensed and developed in the open. Read the code, fork it, ship it.

Community driven

Roadmaps, reviews and decisions happen in public. Contributors of every level are welcome.
